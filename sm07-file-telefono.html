File anche sul telefono

Dietro le icone colorate lo smartphone è organizzato in cartelle, proprio come un computer: sapere quali sono ti evita di «perdere» i documenti.

iOS fa a modo suo

Su iPhone non c'è una cartella unica: ogni app custodisce i propri contenuti. L'app File li raccoglie in «Sul mio iPhone» e in iCloud Drive.

🗺️

La mappa di Android

  • DCIM — foto e video scattati con la fotocamera.
  • Download — tutto ciò che scarichi dal browser o dalle email.
  • Documents — PDF e file di lavoro salvati dalle app.
  • Android/data — dati interni delle app: meglio non toccarli.
Fonte: Manuale utente iPhone — Apple ↗Fonte: Guida ufficiale Android ↗

L'app File

È l'«Esplora risorse» del telefono: cerca, sposta, rinomina e cancella senza dover aprire le singole app. Mostra insieme memoria locale e cloud collegati.

Gestione file su Android

  • Si chiama «Files di Google» o «Gestione file», a seconda del produttore.
  • Organizza per categorie: Immagini, Video, Audio, Download.
  • La funzione «Libera spazio» segnala doppioni e file inutili da eliminare.
🍎

Su iPhone

  • L'app si chiama proprio «File» ed è preinstallata.
  • Due sezioni: «Sul mio iPhone» (memoria locale) e «iCloud Drive» (cloud).
  • La scheda Recenti elenca gli ultimi file toccati: perfetta per ritrovare un download al volo.

Download e documenti

Ogni PDF, biglietto o modulo che scarichi finisce da qualche parte — quasi sempre nella cartella Download, che nessuno svuota mai.

Il percorso

Dal browser → cartella Download. Gli allegati email si aprono in anteprima e restano salvati solo se tocchi «Salva» o li condividi. Su iPhone: app File → Download.

🧹

Routine anti-accumulo

  • Una volta al mese apri Download: via scontrini scaduti, biglietti usati e doppioni.
  • I documenti da conservare spostali in una cartella con un nome sensato, o caricali sul cloud per averli anche da PC.
  • Non ritrovi un file? Usa la ricerca per nome dell'app File: copre tutta la memoria.

Foto, video e allegati

La voce che pesa di più sulla memoria: un minuto di video in 4K può superare il mezzo gigabyte.

📸

Dalla fotocamera

Scatti doppi, raffiche e screenshot si accumulano in silenzio nella galleria (cartella DCIM), spesso a decine ogni settimana.

💬

Dalle chat

WhatsApp e Telegram salvano una copia locale di ogni foto e video ricevuto. Il download automatico dei media si può spegnere nelle impostazioni della chat.

🧭

Da dove iniziare

Nella galleria parti dagli album «Screenshot» e «WhatsApp»: si svuotano senza rimpianti. Le foto vere valutale per ultime, con calma.

Cloud e backup

Il cloud archivia file accessibili da qualsiasi dispositivo; il backup automatico protegge i dati in caso di perdita o furto.

Regola: cancellare dalla galleria non cancella dal cloud.
Sincronizzazione: il file vive sul telefono e nel cloud
☁️

Sincronizzare oltre il telefono

  • Cloud storage (Drive, iCloud, OneDrive, Dropbox) sincronizza i file in tempo reale su tutti i dispositivi.
  • Il backup automatico del telefono include app, impostazioni, messaggi e foto.
  • Controlla che il backup sia attivo e aggiornato: Impostazioni → account cloud → Backup.
  • Lo spazio gratuito (15 GB Google, 5 GB iCloud) si esaurisce: valuta un abbonamento se il telefono è il tuo strumento principale.

Spazio e cache

La cache velocizza le app ma accumula dati temporanei inutilizzati; svuotarla libera spazio senza perdere dati.

💾

Liberare i gigabyte nascosti

  • Lo spazio pieno rallenta il telefono: sistema e app hanno bisogno di spazio libero per funzionare bene.
  • La cache è dati temporanei per caricare le app più velocemente: può crescere a diversi gigabyte.
  • Android: Impostazioni → App → seleziona app → Svuota cache. iOS gestisce la cache automaticamente.
  • Prima di cancellare file: controlla cosa pesa di più in Impostazioni → Memoria → Analizza.

Trasferire a PC

Spostare file tra telefono e computer si fa via cavo USB, WiFi o cloud — ogni metodo ha velocità e casi d'uso diversi.

Metodo più veloce

WiFi: Nearby Share (Android) o AirDrop (iOS su Mac). Da Android a PC Windows: cavo USB, poi scegli "Trasferimento file". Da iPhone: Finder su Mac o cloud. Per molti file: cavo USB è il più veloce e affidabile.

🖥️

Tre strade: cavo, aria, cloud

  • USB: collega il cavo, scegli "Trasferimento file" (Android) o usa Finder/iTunes (iOS).
  • WiFi diretto: Nearby Share su Android, AirDrop su Apple, per file singoli senza cavo.
  • Cloud: carica su Drive o OneDrive dal telefono, scarica dal PC — comodo ma richiede connessione.

Dove portare i dati: quattro destinazioni

💾

Drive esterno

  • Chiavetta o disco USB: paghi una volta, i dati restano in mano tua
  • Ma si rompe, si perde, e la copia non si aggiorna da sola
☁️

Cloud gratuito

  • Google Drive, iCloud: comodo e automatico, zero spese
  • Spazio limitato (circa 15 GB) e i dati vivono sui server di un'azienda
💶

Cloud a pagamento

  • Pochi euro al mese per centinaia di GB, backup automatico e sincronizzazione
  • È un affitto: smetti di pagare, lo spazio si restringe
🏠

Self-hosted

  • Un tuo dispositivo (NAS) che fa da cloud personale: controllo totale
  • Richiede competenza e manutenzione: l'assistenza tecnica sei tu

Come scegliere la destinazione

📏

Quanto e cosa

  • Poche foto → basta il cloud gratuito
  • Archivi grandi o video → disco esterno o cloud a pagamento
  • Dati riservati → drive esterno o self-hosted, fuori dai server altrui
⚖️

Le domande giuste

  • Quanto mi costa all'anno — e per sempre?
  • Se il servizio chiude o smetto di pagare, come riprendo i dati?
  • Chi altri può leggerli, lì dove stanno?
Regola: i dati importanti stanno in due posti diversi, di cui uno sotto il tuo controllo — è la regola 3-2-1 di SD06.

Condivisione file

Condividere tramite link mantiene il controllo sul file; inviare una copia cede quel controllo.

Link vs copia

Condividere via link (Drive, iCloud) non crea duplicati e permette di revocare l'accesso. Inviare il file crea una copia che non controlli più. Per documenti di lavoro preferisci sempre il link condivisibile.

🔗

Copia vs link

  • Inviare il file via WhatsApp o email crea una copia su ogni dispositivo: nessun controllo su chi la ridistribuisce.
  • Un link condiviso è revocabile, tracciabile e non duplica il file su ogni dispositivo.
  • Per file grandi, i link cloud evitano i limiti di dimensione delle chat e delle email.

File sensibili

Documenti personali fotografati non vanno lasciati nella galleria aperta: usare cartelle protette o app con lock.

Dove tenerli

Documenti sensibili (carta d'identità, codice fiscale, referti) in cartella protetta: Samsung Secure Folder, app Note iOS con lock, o app vault cifrata. Non nella galleria principale visibile a tutte le app.

🔒

La galleria non è una cassaforte

  • La galleria foto non è un archivio sicuro: app con accesso alle foto possono vederle tutte.
  • Foto di documenti, dati bancari e referti medici richiedono protezione aggiuntiva.
  • Una cartella bloccata o cifrata è accessibile solo con PIN separato, anche se lo schermo è sbloccato.

Nomi chiari e cestino

Nomi descrittivi con data permettono di trovare i file subito; il cestino trattiene i file eliminati 30 giorni prima della cancellazione definitiva.

🗂️

Ordine che si mantiene da solo

  • Schema utile: AAAA-MM-GG-descrizione.ext → 2026-06-30-contratto-affitto-v2.pdf. La data in testa permette ordinamento automatico.
  • Evita nomi come "documento.pdf", "foto.jpg", "file1" — impossibili da ritrovare dopo settimane.
  • Il cestino trattiene i file eliminati fino a 30 giorni: utile per errori, non per cancellazioni definitive.
  • Cancellare dalla galleria non cancella dal cloud (Google Foto, iCloud): controlla anche lì.
