Liste come vettori

In Python base un vettore monodimensionale si rappresenta normalmente con una lista ordinata. Gli indici partono da zero.

0
primo elemento
−1
ultimo elemento
vettore = [12, 7, 9, 15] print(vettore[0]) # 12 print(vettore[-1]) # 15 print(vettore[1:3]) # [7, 9] vettore.append(20) vettore.insert(1, 10) vettore.remove(7) ultimo = vettore.pop()

Elaborare un vettore

Le operazioni comuni sono aggregare, cercare, ordinare e costruire una nuova lista senza perdere l'originale.

valori = [12, 7, 9, 15] somma = sum(valori) media = somma / len(valori) minimo = min(valori) massimo = max(valori) ordinati = sorted(valori) sopra_dieci = [x for x in valori if x > 10]

Mutare o creare?

valori.sort() modifica la lista.

sorted(valori) restituisce una nuova lista.

x in valori verifica la presenza; valori.index(x) cerca la posizione ma genera errore se x manca.

Matrici: righe e colonne

Una matrice rettangolare può essere rappresentata come lista di liste. Il primo indice sceglie la riga, il secondo la colonna.

matrice[riga][colonna]
matrice = [ [1, 2, 3], [4, 5, 6], [7, 8, 9] ] centro = matrice[1][1] # 5 matrice[0][2] = 30

Attraversare e costruire matrici

Due cicli annidati visitano ogni cella. Prima di elaborare, controlla che tutte le righe abbiano la stessa lunghezza.

for riga in matrice: for valore in riga: print(valore, end=" ") print() righe = 3 colonne = 4 zeri = [[0 for c in range(colonne)] for r in range(righe)]

Errore da evitare

[[0] * colonne] * righe riusa la stessa lista interna: modificare una cella può cambiare più righe.

Per calcoli matriciali avanzati si usa spesso NumPy; le liste annidate bastano per griglie e piccoli programmi.

Dizionari, tuple e insiemi

Scegli la struttura che esprime meglio le operazioni richieste.

Coppie chiave-valore.

Tupla

punto = (10, 25) x, y = punto

tag = {"python", "csv"} tag.add("json") comuni = tag & altri_tag

Gestire gli errori previsti

try ed except servono quando un'operazione può fallire nonostante il programma sia scritto correttamente.

Regola

Cattura eccezioni specifiche; non usare un except generico che nasconde qualsiasi errore.

try: eta = int(input("Età: ")) except ValueError: print("Inserisci un numero intero") else: print(f"Età registrata: {eta}") finally: print("Operazione terminata")

File di testo: leggere e scrivere

with chiude automaticamente il file anche in caso di errore. Specifica sempre la codifica.

with open("note.txt", "w", encoding="utf-8") as file: file.write("Prima riga\n") file.write("Seconda riga\n")
with open("note.txt", "r", encoding="utf-8") as file: contenuto = file.read() with open("note.txt", "a", encoding="utf-8") as file: file.write("Aggiunta\n")
Modalità: r legge · w riscrive · a aggiunge.

CSV: righe e colonne

Il modulo csv gestisce separatori e virgolette. DictReader e DictWriter usano le intestazioni come chiavi.

import csv with open("prodotti.csv", newline="", encoding="utf-8") as file: lettore = csv.DictReader(file) prodotti = list(lettore) for prodotto in prodotti: print(prodotto["nome"], prodotto["prezzo"])
campi = ["nome", "prezzo"] with open("prodotti.csv", "w", newline="", encoding="utf-8") as file: scrittore = csv.DictWriter(file, fieldnames=campi) scrittore.writeheader() scrittore.writerows(prodotti)

JSON: strutture annidate

JSON rappresenta oggetti, liste, stringhe, numeri, booleani e null: in Python diventano soprattutto dizionari, liste e None.

import json dati = { "corso": "Python", "attivo": True, "voti": [7, 8, 9] } with open("dati.json", "w", encoding="utf-8") as file: json.dump(dati, file, ensure_ascii=False, indent=2)
with open("dati.json", encoding="utf-8") as file: dati = json.load(file) print(dati["corso"]) print(dati["voti"][0])
Fonte: Modulo json — documentazione Python ↗

Scegliere il tipo di file

Il formato dipende dalla struttura e da chi dovrà leggere i dati.

TXT

Testo libero e log. Semplice, ma senza colonne o tipi dichiarati.

CSV

Tabelle piatte: una riga per record, una colonna per campo.

JSON

Dati gerarchici e annidati: configurazioni, API e scambio tra applicazioni.

E XML?

È strutturato tramite tag ed è usato in standard e documenti complessi; per iniziare CSV e JSON coprono i casi più comuni.

La struttura di un programma semplice

Un’applicazione piccola resta gestibile quando separa ingresso, elaborazione, uscita e salvataggio dei dati.

01 · Carica

Leggi dal file i dati già disponibili e prepara lo stato iniziale.

02 · Valida l’input

Converti i valori ricevuti e rifiuta quelli mancanti o non validi.

03 · Elabora

Affida calcoli e trasformazioni a funzioni con un compito preciso.

04 · Presenta

Mostra risultati e messaggi in una forma comprensibile per chi usa il programma.

05 · Salva

Scrivi sul file soltanto dati completi, validi e coerenti.

06 · Gestisci gli errori

Intercetta i fallimenti previsti e comunica come correggerli.

Regola: ogni funzione svolge un compito osservabile e verificabile.

Esempio completo: registro delle spese

Funzioni, lista di dizionari, input controllato, ciclo, JSON e punto di avvio lavorano insieme.

import json from pathlib import Path FILE = Path("spese.json") def carica(): if not FILE.exists(): return [] with FILE.open(encoding="utf-8") as f: return json.load(f) def salva(spese): with FILE.open("w", encoding="utf-8") as f: json.dump(spese, f, indent=2, ensure_ascii=False)
def main(): spese = carica() while True: voce = input("Voce (fine per uscire): ").strip() if voce.lower() == "fine": break try: importo = float(input("Importo: ")) except ValueError: print("Importo non valido") continue spese.append({"voce": voce, "importo": importo}) salva(spese) print(f"Totale: {sum(s['importo'] for s in spese):.2f} €") if __name__ == "__main__": main()

Programmare come sequenza di passi

Nei linguaggi procedurali il programma è un insieme di istruzioni e procedure eseguite in ordine. L'attenzione è sul percorso: cosa fare prima, cosa dopo, quando scegliere e quando ripetere. Come in una ricetta: prima accendi il forno, poi impasti, poi inforni.

Vantaggio

È vicino al modo in cui descriviamo procedure operative e calcoli passo-passo. Si legge riga per riga: ciò che accade al passo 3 dipende solo dai passi 1 e 2.

Rischio

Se il programma cresce senza struttura diventa un blocco unico: per capire una riga devi rileggere tutto ciò che la precede. Le procedure servono proprio a spezzarlo in parti.

1. leggi ordine 2. verifica scorta 3. calcola totale 4. stampa ricevuta

Dallo pseudocodice al programma

Pseudocodice

Serve a controllare la logica senza bloccarci sulla sintassi.

Codice

Traduce la logica in istruzioni precise per un interprete o compilatore.

leggi numero se numero e pari allora scrivi "pari" altrimenti scrivi "dispari"

Debug: osservare il programma mentre lavora

Fare debug significa ricostruire cosa succede davvero durante l'esecuzione. Si controllano input, valori intermedi, rami scelti e punto in cui il comportamento diverge dalle attese.

Stampe

Mostrano valori temporanei.

Breakpoint

Fermano l'esecuzione in un punto.

Traccia

Sviluppare piccoli passi verificabili

Un buon flusso di lavoro alterna progettazione, scrittura, esecuzione e correzione. Meglio costruire programmi piccoli e testabili che scrivere molte istruzioni senza controllarle.

Scrivi poco

Aggiungi una parte alla volta.

Esegui spesso

Controlla subito cosa cambia.

Testa casi

Prova esempi normali, limite e sbagliati.

Spiegare ciò che il codice non dice da solo

I commenti non devono ripetere istruzioni ovvie. Servono per chiarire scelte, vincoli, casi limite e motivi per cui una soluzione è stata preferita a un'altra.

Utile

Spiega una decisione non evidente.

Inutile

Ripete parola per parola il codice.
