Dal linguaggio naturale al linguaggio macchina

Il linguaggio naturale è flessibile ma ambiguo: «metti in ordine questi file» è chiaro per un collega, ma la macchina non sa se ordinare per nome, per data, crescente o decrescente. Il linguaggio macchina è eseguibile ma illeggibile. I linguaggi di programmazione stanno nel mezzo: formali come la matematica, leggibili quasi come una frase.

Naturale

Comodo per spiegare, rischioso per eseguire: sottintesi, contesto, ambiguità. Perfetto per raccogliere requisiti, inadatto come istruzione diretta.

Macchina

Sequenze binarie come 10110000 01100001, eseguite direttamente dal processore. Velocissime, ma illeggibili e diverse per ogni famiglia di CPU.

Alto livello

Python, JavaScript, C: parole chiave leggibili e regole precise. Un compilatore o interprete le traduce in linguaggio macchina al posto tuo.

Python: un primo ponte verso il codice

Python è adatto per iniziare: sintassi leggibile, poca cerimonia, risultato immediato. Queste otto righe sono già un programma completo: chiedono dati, li convertono, decidono e rispondono.

nome = input("Come ti chiami? ") print("Ciao " + nome) eta = int(input("Eta: ")) if eta >= 18: print("Maggiorenne") else: print("Minorenne")

Riga per riga

input() mostra la domanda e restituisce ciò che scrivi, sempre come testo. int() lo trasforma in numero. if confronta e sceglie il ramo: con 25 stampa «Maggiorenne», con 15 stampa «Minorenne».

Errore comune: dimenticare int(). input() restituisce una stringa, e confrontare "15" >= 18 produce un errore di tipo.

Simboli fondamentali nella sintassi

Ogni linguaggio usa simboli per separare blocchi, argomenti, liste, stringhe e commenti. Riconoscerli aiuta a leggere codice nuovo.

() chiamata o raggruppamento [] liste o indici {} blocchi o dizionari , separa argomenti : introduce blocchi in Python # commento in Python

I blocchi: istruzioni che lavorano insieme

Un blocco è un gruppo di istruzioni trattato come un’unità: Python lo esegue quando entra in una condizione, in un ciclo o in una funzione.

eta = 70 if eta >= 18: # apre il blocco print("Maggiorenne") # dentro il blocco if eta >= 65: print("Senior") # blocco annidato print("Fine controllo") # fuori dai blocchi

Come si riconosce un blocco

  1. I due punti introducono il blocco dopo istruzioni come if, for, while e def.
  2. Le righe con lo stesso rientro appartengono allo stesso blocco e vengono eseguite in sequenza.
  3. Un rientro più profondo crea un blocco annidato dentro quello corrente.
  4. Quando il codice torna al livello precedente, il blocco è terminato.
Regola: usa quattro spazi per livello e non mescolare spazi e tabulazioni.

Rappresentare i dati prima di elaborarli

Un programma non tocca oggetti reali: lavora su dati rappresentati in modo formale. Scegliere il tipo giusto fin dall'inizio rende più semplice scrivere l'algoritmo e previene errori: non puoi moltiplicare un testo, né mettere in maiuscolo un numero.

Numeri

Per calcoli, misure, contatori e indici: eta = 25, prezzo = 12.50. Si possono sommare, confrontare, dividere e usare per calcolare medie e totali.

Stringhe

Sequenze di caratteri tra virgolette: nome = "Giulia". Servono per nomi, messaggi, indirizzi. Anche "25" è una stringa: sembra un numero, ma non lo è.

Booleani

Solo due valori: True o False. attivo = True. Guidano ogni decisione del programma: entrare in un ramo, ripetere un ciclo, filtrare una tabella.

Errore comune

"23" + "1" produce "231", perché incolla due testi; 23 + 1 produce 24. Stesso simbolo +, tipi diversi, risultati opposti: per questo il tipo va scelto con cura.

Conversione dei tipi: quando un valore deve cambiare

Molti input arrivano come testo, anche quando rappresentano numeri. Convertire significa trasformare il valore nel tipo necessario per l'operazione successiva.

eta_testo = "18" eta = int(eta_testo) if eta >= 18: print("ok")

Conservare più valori insieme

Una lista raccoglie più elementi in una sola struttura. Permette di attraversare dati simili con un ciclo, calcolare statistiche o cercare elementi.

voti = [7, 8, 6, 9] totale = 0 for voto_corrente in voti: totale += voto_corrente

Stringhe: testo da elaborare

Le stringhe sono immutabili: ogni operazione produce un nuovo testo, senza modificare quello di partenza.

nome = " Ada Lovelace " pulito = nome.strip() print(pulito.lower()) print(pulito.upper()) print(pulito.replace("Ada", "A.")) parole = pulito.split() email = "@".join(["ada", "azienda.it"]) messaggio = f"Ciao {pulito}!"
  • strip() rimuove gli spazi bianchi alle estremità.
  • lower() restituisce il testo in minuscolo.
  • upper() restituisce il testo in maiuscolo.
  • replace("Ada", "A.") sostituisce il primo testo con il secondo.
  • split() divide il testo in parole usando gli spazi bianchi.
  • "@".join(...) unisce gli elementi inserendo @ tra uno e l’altro.
  • La f prima delle virgolette crea una f-string: ciò che è tra graffe, come {pulito}, viene sostituito con il suo valore.

Scegliere con if, elif ed else

Le condizioni vengono valutate dall'alto: Python esegue il primo ramo vero e salta gli altri.

voto = int(input("Voto: ")) if voto < 0 or voto > 10: print("Valore non valido") elif voto >= 8: print("Ottimo") elif voto >= 6: print("Sufficiente") else: print("Da recuperare")

Tre condizioni frequenti in Python

Appartenenza, assenza di un valore e contenitori vuoti si controllano direttamente, senza confronti inutilmente lunghi.

Appartenenza con in

scelta = "s" if scelta in ["s", "n"]: print("Scelta valida")

in restituisce True quando il valore è presente nella sequenza.

Assenza con is None

risultato = None if risultato is None: print("Nessun dato")

is verifica che due nomi indichino lo stesso oggetto, non soltanto valori uguali. Poiché None è un oggetto unico che rappresenta l’assenza di un valore, il controllo corretto è is None.

Vuoto o non vuoto

righe = [] if righe: print("Dati presenti") else: print("Lista vuota")

Una stringa o lista vuota vale False; una non vuota vale True.

Ripetere con for e range

Il ciclo for attraversa una sequenza. range genera numeri e non include il limite finale.

Elementi

for elemento in nomi:
lavora direttamente su ogni valore.

for prodotto in prodotti: print(prodotto)

Contatore

for i in range(5):
produce 0, 1, 2, 3, 4.

for i in range(5): print(i)

Indice e valore

for i, nome in enumerate(nomi):
restituisce entrambi.

for posizione, prodotto in enumerate(prodotti, start=1): print(posizione, prodotto)

Ripetere finché serve

while continua finché la condizione resta vera. break termina il ciclo; continue passa all'iterazione successiva.

⚠️ Evita il ciclo infinito

Dentro il ciclo deve cambiare almeno un valore coinvolto nella condizione.

tentativi = 3 while tentativi > 0: password = input("Password: ") if password == "corretta": break tentativi -= 1
for numero in range(10): if numero % 2 == 0: continue print(numero)

Come avanza il ciclo while

  1. Python controlla la condizione prima di ogni giro: se è già falsa, il corpo non viene eseguito.
  2. Se è vera, esegue nell’ordine tutte le istruzioni indentate nel corpo.
  3. Alla fine torna alla condizione: nell’esempio, tentativi -= 1 avvicina il ciclo alla conclusione.
  4. break esce subito dal ciclo; continue salta il resto del giro e passa al controllo successivo.

Funzioni: dare un nome a un compito

Una funzione raccoglie istruzioni riutilizzabili. I parametri ricevono dati e return restituisce il risultato.

def calcola_totale(prezzo, quantita=1): totale = prezzo * quantita return round(totale, 2) spesa = calcola_totale(12.5, 3) print(spesa)

Contratto della funzione

def: è la parola chiave che definisce una nuova funzione. È seguita dal nome, dai parametri tra parentesi e dai due punti; il corpo della funzione va indentato.

Nome: descrive l'azione.

Parametri: ciò che serve per lavorare. Con nome=valore si assegna un valore predefinito: nell’esempio, quantita=1 viene usato quando il secondo argomento non è specificato.

Return: il risultato da usare altrove.

Una funzione senza return restituisce None.

Variabili locali: dove esistono i nomi

Parametri e variabili create dentro una funzione appartengono a quella chiamata: fuori dal suo corpo quei nomi non sono disponibili.

def calcola_area(base, altezza): area = base * altezza return area risultato = calcola_area(5, 4) print(risultato) # Qui "area" non è definita # print(area)

Il confine è il corpo della funzione

  • base e altezza sono parametri locali: ricevono un valore a ogni chiamata.
  • area nasce dentro calcola_area() e smette di essere accessibile quando la funzione termina.
  • return trasferisce il valore calcolato all’esterno, non rende visibile la variabile locale.
  • Fuori dalla funzione il valore restituito viene assegnato a un altro nome: qui risultato.
In pratica: per comunicare tra funzioni, passa argomenti e restituisci risultati.

Il programma principale con main()

main non è una parola chiave di Python: è il nome convenzionale della funzione che coordina l’avvio del programma.

def chiedi_intero(messaggio): return int(input(messaggio)) def main(): base = chiedi_intero("Base: ") altezza = chiedi_intero("Altezza: ") area = base * altezza print(f"Area: {area}") if __name__ == "__main__": main()

1. Definizioni

def associa un nome al corpo della funzione, senza eseguirlo subito.

2. Coordinamento

main() raccoglie input, chiamate alle funzioni e output iniziali.

3. Il controllo decide se avviarlo

Ogni modulo possiede __name__. Con python programma.py vale "__main__", quindi la condizione è vera e parte main(). Con import programma vale invece "programma": le funzioni vengono definite e restano disponibili, ma la chiamata indentata sotto il controllo viene saltata. Così l’importazione non avvia domande o stampe indesiderate e il codice può essere riusato e testato.

Moduli: usare codice già pronto

import rende disponibili funzioni, classi e costanti. La libreria standard copre molti compiti senza installare pacchetti.

import math radice = math.sqrt(81) from random import randint dado = randint(1, 6) import statistics as stats media = stats.mean([7, 8, 9])

Le tre sintassi generali

Modulo intero: import nome_modulo
Gli elementi si usano come nome_modulo.nome.

Un nome dal modulo: from nome_modulo import nome
Il nome importato si usa direttamente.

Modulo con alias: import nome_modulo as alias
Gli elementi si richiamano come alias.nome.

Regola: evita from modulo import *: nasconde l'origine dei nomi.
