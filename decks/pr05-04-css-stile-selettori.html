CSS:
stile e selettori

Il linguaggio che controlla l’aspetto delle pagine: caratteri, colori, spazi, scatole e regole riutilizzabili.

Francesco Antonio Binetti

Separare contenuto e aspetto

HTML dice cosa è una cosa; il CSS dice come appare: colori, dimensioni, spazi, posizioni. Sono due mestieri distinti, ed è giusto tenerli separati.

Analogia: l’HTML è lo scheletro, il CSS è il vestito.
/* CSS */ h1 { color: teal; font-size: 40px; } p { line-height: 1.5; }

Peso e inclinazione

HTML può indicare un testo in grassetto o in corsivo; il CSS controlla invece come viene disegnato il carattere.

<b> e font-weight

<b> richiama l’attenzione su un testo, mostrato normalmente in grassetto. In CSS, font-weight controlla il peso: 400 è regolare, 700 è grassetto.

<b>Testo in grassetto</b> p { font-weight: 700; }

<i> e font-style

<i> distingue una voce, un termine o un’espressione, mostrati normalmente in corsivo. In CSS, font-style: italic controlla l’inclinazione.

<i>Testo in corsivo</i> p { font-style: italic; }
Regola: <b> e <i> distinguono; <strong> e <em> aggiungono significato; il CSS decide l’aspetto.

Dimensione e famiglia

La leggibilità dipende sia da quanto è grande il testo sia dalla forma dei caratteri con cui viene composto.

font-size

Imposta la dimensione. px è una misura fissa; rem è relativa alla dimensione di base della pagina e si adatta meglio alle preferenze dell’utente.

body { font-size: 1rem; } h1 { font-size: 3rem; }

font-family

Indica il carattere desiderato e una serie di alternative. Il browser usa il primo disponibile; l’ultima voce dovrebbe essere una famiglia generica.

body { font-family: "Space Grotesk", Arial, sans-serif; }
💡 Leggibilità

Una gerarchia coerente usa poche dimensioni e poche famiglie: il titolo deve distinguersi, non competere con ogni paragrafo.

Anatomia di una regola CSS

Una regola collega un gruppo di elementi alle dichiarazioni che ne controllano l’aspetto.

p { color: #163b35; font-size: 1.2rem; }

Selettore

p indica quali elementi ricevono lo stile.

Dichiarazione

color: #163b35; associa una proprietà a un valore e termina con il punto e virgola.

Blocco

Le parentesi graffe raccolgono tutte le dichiarazioni della stessa regola.

Il punto e virgola nel CSS

Il carattere ; chiude una dichiarazione e indica al browser dove può iniziare la proprietà successiva.

Con il punto e virgola

p { color: red; font-size: 1.2rem; }

Le due dichiarazioni sono separate e il browser può leggerle entrambe.

Senza il separatore

p { color: red font-size: 1.2rem; }

Il browser può interpretare le due righe come un unico valore non valido e ignorarle.

Regola: scrivi ; dopo ogni dichiarazione, anche dopo l’ultima: rende sicure le aggiunte successive.

Creare uno stile, passo per passo

Una classe permette di progettare uno stile una volta e applicarlo a tutti gli elementi che devono avere lo stesso aspetto.

1 · Scegli un nome

Usa un nome che descriva la funzione dello stile, per esempio avviso.

.avviso

2 · Scrivi la regola

Nel CSS, il punto indica una classe. Le dichiarazioni definiscono l’aspetto.

.avviso { color: #a62920; font-weight: 700; }

3 · Applica la classe

Nell’HTML, assegna lo stesso nome con l’attributo class, senza il punto.

<p class="avviso"> Scadenza domani </p>
In pratica: .avviso nel CSS trova ogni elemento con class="avviso" nell’HTML.

Dove si scrive il CSS

Lo stesso linguaggio può essere collegato all’HTML in tre modi. Cambia dove vive la regola, non la sua sintassi.

MetodoDoveEsempioQuando usarlo
In lineaNell’attributo style<p style="color:red">Prove rapide; difficile da mantenere
InternoNel tag <style> dentro <head><style> p { … } </style>Una singola pagina autonoma
EsternoIn un file .css collegato<link rel="stylesheet" href="stile.css">Più pagine con lo stesso stile
In pratica: per un sito usa normalmente un file esterno; separa contenuto e presentazione e riutilizza le regole.

Scegliere gli elementi

Il selettore stabilisce a quali elementi applicare una regola: per nome, per classe riutilizzabile o per identificatore unico.

Elemento

p { color: #333; }

Seleziona tutti i paragrafi della pagina.

Classe

.nota { color: red; }

Seleziona ogni elemento con class="nota". È il metodo più riutilizzabile.

Identificatore

#menu { color: blue; }

Seleziona l’elemento con id="menu", che deve essere unico nella pagina.

💡 Combinare

p.nota seleziona soltanto i paragrafi che hanno la classe nota: il selettore diventa più preciso.

Quando due regole competono

Il browser deve decidere quale valore applicare quando più regole modificano la stessa proprietà dello stesso elemento.

1 · Importanza e origine

Le regole del sito, quelle dell’utente e gli stili del browser non hanno sempre la stessa priorità. Evita !important finché non ne comprendi l’effetto.

2 · Specificità

Un identificatore è più specifico di una classe; una classe è più specifica del nome di un elemento.

3 · Ordine

Se due regole hanno la stessa priorità e specificità, prevale quella scritta più tardi.

p { color: teal; } .nota { color: red; /* prevale con class="nota" */ }

Il modello a scatola

Ogni elemento occupa una scatola. Capire i suoi quattro strati evita spaziature casuali e dimensioni difficili da prevedere.

Dall’interno verso l’esterno

Contenuto

Testo o immagine, con larghezza e altezza proprie.

Padding e bordo

Il padding crea spazio interno; il bordo delimita la scatola.

Margine

Crea spazio esterno e separa la scatola dagli elementi vicini.

Commenti: sintassi diverse

Un commento documenta il codice o esclude temporaneamente istruzioni. La sintassi dipende dal linguaggio in cui stai scrivendo.

HTML

<!-- Nota per chi legge il sorgente -->

Può occupare una o più righe. Non appare nella pagina, ma resta visibile nel codice sorgente: non inserirci password o dati riservati.

CSS

/* Colore del titolo */

La coppia /* … */ commenta una parte di riga o più righe. In CSS la forma // non è un commento valido.

JavaScript: una riga

// Controlla il valore

// ignora tutto ciò che segue fino alla fine della riga. È utile per note brevi accanto a un’istruzione.

JavaScript: più righe

/* Controllo su più righe */

/* … */ racchiude un commento esteso. I commenti non si annidano: una seconda apertura interna non crea un nuovo livello.

Lo stile diventa un sistema.

Sai collegare il CSS, costruire regole, scegliere i selettori e controllare testo, colore, spazi e priorità senza confondere struttura e presentazione.
