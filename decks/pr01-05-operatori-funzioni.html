Operatori aritmetici: somma, sottrazione, prodotto

Gli operatori aritmetici trasformano numeri in altri numeri. Sono la base di calcoli, statistiche, coordinate, prezzi, tempi e quantità.

prezzo = 12 quantita = 3 totale = prezzo * quantita sconto = totale * 0.10 finale = totale - sconto

Divisione, resto e divisione intera

La divisione produce un quoziente; il resto dice cosa avanza. Sono utili per turni, gruppi, pagine, pari/dispari e distribuzioni.

17 / 5 → 3.4 17 // 5 → 3 17 % 5 → 2 numero % 2 == 0 → pari

Potenza, radici e precedenza

La precedenza decide cosa viene calcolato prima. Le parentesi rendono la formula leggibile e impediscono ambiguità.

2 + 3 * 4 → 14 (2 + 3) * 4 → 20 2 ** 3 → 8 area = base * altezza

Incrementi, decrementi e accumuli

Molti algoritmi aggiornano una variabile a partire dal suo valore precedente: contatori, totali, medie progressive, inventari.

contatore = contatore + 1 totale = totale + prezzo scorta = scorta - venduti saldo += versamento

Esempi pratici di formule numeriche

La stessa logica appare in gestionali, fogli di calcolo e app: calcolo prezzo, IVA, durata, percentuali, punteggi.

iva = imponibile * 0.22 lordo = imponibile + iva percentuale = parte / totale * 100 media = somma / numero_valori

I sei confronti fondamentali

Un operatore relazionale mette in relazione due operandi e produce un valore booleano. Le sei relazioni numeriche standard coprono uguaglianza, disuguaglianza e ordinamento.

==

Uguale a: nome == "Luca".

!=

Diverso da: stato != "annullato".

>

Maggiore di: saldo > 0.

<

Minore di: prezzo < budget.

>=

Maggiore o uguale: eta >= 18.

<=

Minore o uguale: scorta <= soglia.

La relazione è la stessa, il simbolo cambia

La matematica usa simboli tipografici; i linguaggi scelgono sequenze disponibili sulla tastiera. Prima di scrivere una condizione bisogna conoscere la convenzione dell’ambiente.

Proposizioni e condizioni

La logica trasforma affermazioni in condizioni che il programma può controllare da solo. Una condizione è una domanda con risposta secca: vero oppure falso, senza vie di mezzo. «Il cliente è affidabile» non è una condizione; «il cliente ha pagato le ultime 3 fatture» lo è, perché si misura sui dati.

eta >= 18 # con eta = 20 → vero password == salvata # identiche? saldo > 0 # con saldo = -5 → falso

Uso pratico

Le condizioni guidano scelte (se piove, avvisa), filtri (mostra solo ordini pagati), controlli di validità (l'email contiene una @?) e cicli (ripeti finché scorta > 0).

Errore comune

Scrivere condizioni che i dati non possono verificare. Il programma non sa se «l'utente è di fretta»: sa solo confrontare valori che possiede davvero, come numeri, testi e date.

AND, OR, NOT

I connettivi combinano condizioni semplici in una decisione complessa. Esempio guida: un negozio applica lo sconto se la spesa supera 50 € E il cliente ha la tessera fedeltà.

AND

Vero solo se tutte le condizioni sono vere. Spesa 60 € con tessera → sconto. Spesa 60 € senza tessera → niente. Spesa 40 € con tessera → niente.

OR

Vero se almeno una condizione è vera. Entrata ridotta se sei socio O hai un invito: basta una delle due, e averle entrambe va bene comunque.

NOT

Inverte il valore logico: not vero diventa falso. «Se NON registrato, mostra il modulo di iscrizione». Evita le doppie negazioni: confondono chi legge.

se spesa > 50 AND tessera allora applica sconto 10% fine se

AND: tutte le condizioni devono essere vere

AND serve quando un’azione richiede più requisiti contemporaneamente.

eta >= 18 and documento_valido prezzo > 0 and quantita > 0 utente_attivo and password_corretta scorta > 0 and ordine_pagato

OR: basta una condizione vera

OR serve per alternative equivalenti: più strade portano allo stesso risultato.

ruolo == "admin" or ruolo == "editor" pagamento == "carta" or pagamento == "paypal" giorno == "sabato" or giorno == "domenica" sconto_cliente or coupon_valido

NOT: invertire una condizione

NOT rende esplicito il contrario. È utile per controllare assenze, blocchi e casi non consentiti.

not trovato not utente_bloccato not email_verificata if not lista_vuota: elabora()

Combinare condizioni con parentesi

Quando AND e OR convivono, le parentesi rendono esplicito cosa appartiene a ogni parte della decisione. In Python si possono anche concatenare confronti riferiti allo stesso valore.

(eta >= 18 and documento_valido) or autorizzazione_genitore (prezzo > 0 and quantita > 0) and not annullato ruolo == "admin" or (ruolo == "staff" and turno_attivo) 0 <= voto <= 10 # Python: concatenamento voto >= 0 and voto <= 10 # forma esplicita equivalente
Attenzione

Il concatenamento non ha lo stesso significato in tutti i linguaggi: in C, Java e C# conviene scrivere i due confronti collegati da AND.

Assegnazione semplice: il segno =

In programmazione = non significa “uguale” matematico: significa prendi il valore a destra e salvalo nel nome a sinistra.

totale = 0 nome = "Giulia" attivo = True prezzo_finale = prezzo - sconto

Assegnazioni composte

Gli operatori composti aggiornano una variabile usando il suo valore precedente. Sono abbreviazioni molto comuni.

x += 1 # x = x + 1 x -= 2 # x = x - 2 x *= 3 # x = x * 3 x /= 4 # x = x / 4 x %= 2 # x = x % 2

Uguale, confronto e identità

Molti bug nascono dalla confusione tra assegnare, confrontare e controllare identità o equivalenza.

x = 5 # assegna x == 5 # confronta valore x != 5 # diverso x is None # identità/speciale in Python

Scegliere l’operatore giusto

Prima chiediti che tipo di risultato vuoi: numero, vero/falso, aggiornamento di variabile o struttura sintattica.

numero → + - * / // % ** booleano → == != > < >= <= and or not aggiornamento → = += -= *= /= struttura → () [] {} , : .

Funzioni: separare una responsabilità

Una funzione riceve dati, esegue un compito e può restituire un risultato. Aiuta a rendere il programma più corto, leggibile e testabile.

def area_rettangolo(base, altezza): return base * altezza area = area_rettangolo(5, 3)

Dove vive una variabile

Lo scope indica in quale parte del programma un nome è visibile. Capirlo evita confusione tra variabili locali, parametri e valori globali.

Variabili locali

Esistono dentro una funzione o un blocco specifico.

Variabili globali

Sono accessibili da più parti, ma vanno usate con prudenza.

Controllare funzioni piccole

Una funzione con input e output chiari può essere testata con esempi semplici. Questo riduce il rischio che errori nascosti si sommino nel programma completo.

area_rettangolo(5, 3) → 15 area_rettangolo(0, 3) → 0 area_rettangolo(2, 2) → 4

Gli stessi operatori, ora in un linguaggio.

Prima di ripetere i calcoli, impariamo a distinguere valori, misure e unità: è ciò che rende significativi input e risultati.
