Classi e oggetti Una classe descrive quali dati e comportamenti condividono oggetti dello stesso tipo. Ogni oggetto conserva però il proprio stato. Analogia: la classe è il progetto; l'oggetto è una costruzione concreta. Conto saldo 120 saldo 50 saldo 900 Stessa struttura, stato indipendente

--- Slide 3 ---
Costruire un oggetto con __init__ Il costruttore riceve i dati iniziali. self indica l'oggetto sul quale il metodo sta lavorando. class Prodotto:
 def __init__(self, nome, prezzo):
 self.nome = nome
 self.prezzo = prezzo

penna = Prodotto("Penna", 1.50) Cosa accade Prodotto(...) crea un nuovo oggetto. self.nome e self.prezzo sono attributi dell'istanza. Ogni prodotto può avere valori diversi.

--- Slide 4 ---
I metodi proteggono lo stato Un metodo esprime un'operazione ammessa sull'oggetto e può controllare che lo stato rimanga valido. class Conto:
 def __init__(self, saldo=0):
 self.saldo = saldo

 def deposita(self, importo):
 if importo &lt;= 0:
 raise ValueError("Importo non valido")
 self.saldo += importo Stato saldo descrive la situazione corrente dell'oggetto. Regola deposita() impedisce che un importo nullo o negativo modifichi il conto.

--- Slide 7 ---
Iterable e iteratori Un iterable può produrre elementi; un iteratore ricorda il punto raggiunto e restituisce il valore successivo. Iterable Liste, stringhe, dizionari, file e molti altri oggetti attraversabili. iter() Chiede all'oggetto un iteratore. next() Ottiene il prossimo elemento; alla fine arriva StopIteration . In pratica: il ciclo for usa questo protocollo automaticamente.

--- Slide 8 ---
Consumare un iteratore una volta Un iteratore avanza: dopo aver restituito un elemento non torna indietro, a meno di crearne uno nuovo. numeri = iter([10, 20, 30])

print(next(numeri)) # 10
print(next(numeri)) # 20
print(next(numeri)) # 30 ⚠️ Attenzione Liste e tuple si possono attraversare più volte. Un iteratore o un file aperto, invece, può essere già consumato.

--- Slide 9 ---
Generatori: produrre valori con yield Una funzione generatrice sospende il lavoro a ogni yield e riprende dalla stessa riga alla richiesta successiva. def quadrati(limite):
 for n in range(limite):
 yield n * n

for valore in quadrati(4):
 print(valore)
# 0, 1, 4, 9 Perché serve Non costruisce subito l'intera collezione: produce un valore alla volta. Questo riduce la memoria e permette di lavorare con sequenze molto grandi.
Fonti ufficiali:
- Generatori — Python Functional Programming HOWTO — https://docs.python.org/3/howto/functional.html#generators

--- Slide 10 ---
Espressioni generatrici Assomigliano alle list comprehension, ma usano parentesi tonde e calcolano i valori soltanto quando servono. Lista immediata quadrati = [n*n for n in range(1_000_000)] Occupa memoria per tutti i risultati. Generatore pigro quadrati = (n*n for n in range(1_000_000)) Conserva soltanto lo stato necessario per continuare.

--- Slide 11 ---
Pipeline: filtrare senza caricare tutto Generatori collegati formano una pipeline: ogni fase riceve un elemento, lo trasforma o lo scarta e lo passa avanti. righe = (riga.strip() for riga in file)
non_vuote = (riga for riga in righe if riga)
importi = (float(riga) for riga in non_vuote)

totale = sum(importi) Regola: utile per log, grandi CSV e flussi che non devono stare tutti in memoria. [Fonte: Generatori — Python Functional Programming HOWTO — https://docs.python.org/3/howto/functional.html#generators]

--- Slide 17 ---
Un test rende verificabile una promessa Un test prepara un caso, esegue il comportamento e confronta il risultato con ciò che dovrebbe accadere. Arrange Prepara dati e dipendenze. Act Esegue la funzione o il metodo. Assert Confronta risultato ottenuto e atteso. Regola: un test deve fallire per un motivo comprensibile.

--- Slide 18 ---
Assert: il controllo minimo L'istruzione assert esprime una condizione che deve essere vera. È utile nei test e per invarianti interne, non per validare input utente. def media(valori):
 if not valori:
 raise ValueError("Lista vuota")
 return sum(valori) / len(valori)

assert media([6, 8, 10]) == 8 ⚠️ Distinzione Gli assert possono essere disattivati dall'interprete. Per errori previsti dell'utente usa eccezioni esplicite.

--- Slide 19 ---
Test strutturati con unittest La libreria standard scopre classi e metodi di test, raccoglie risultati e mostra errori riproducibili. import unittest

class TestMedia(unittest.TestCase):
 def test_valori_normali(self):
 self.assertEqual(media([6, 8, 10]), 8)

 def test_lista_vuota(self):
 with self.assertRaises(ValueError):
 media([])

if __name__ == "__main__":
 unittest.main()

 self.assertEqual(

--- Slide 27 ---
Creare tabella e connessione Il blocco with db conferma o annulla la transazione; finally chiude la connessione anche in caso di errore. import sqlite3

db = sqlite3.connect("negozio.db")
try:
 with db:
 db.execute("""
 CREATE TABLE IF NOT EXISTS prodotti (
 id INTEGER PRIMARY KEY,
 nome TEXT NOT NULL,
 prezzo REAL NOT NULL CHECK (prezzo &gt;= 0)
 )
 """)
finally:
 db.close()

--- Slide 28 ---
Parametri SQL, mai concatenazione I segnaposto separano istruzione e dati, gestiscono correttamente i tipi e prevengono SQL injection. Da evitare sql = "SELECT * FROM prodotti WHERE nome = '" + nome + "'" Il dato può cambiare il significato della query. Corretto righe = db.execute(
 "SELECT * FROM prodotti WHERE nome = ?",
 (nome,),
).fetchall() La query resta separata dal valore.
