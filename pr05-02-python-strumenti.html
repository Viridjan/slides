Classi e oggetti

Una classe descrive quali dati e comportamenti condividono oggetti dello stesso tipo. Ogni oggetto conserva però il proprio stato.

Analogia: la classe è il progetto; l'oggetto è una costruzione concreta.
Stessa struttura, stato indipendente

Costruire un oggetto con __init__

Il costruttore riceve i dati iniziali. self indica l'oggetto sul quale il metodo sta lavorando.

class Prodotto: def __init__(self, nome, prezzo): self.nome = nome self.prezzo = prezzo penna = Prodotto("Penna", 1.50)

Cosa accade

Prodotto(...) crea un nuovo oggetto.

self.nome e self.prezzo sono attributi dell'istanza.

Ogni prodotto può avere valori diversi.

I metodi proteggono lo stato

Un metodo esprime un'operazione ammessa sull'oggetto e può controllare che lo stato rimanga valido.

class Conto: def __init__(self, saldo=0): self.saldo = saldo def deposita(self, importo): if importo <= 0: raise ValueError("Importo non valido") self.saldo += importo

Stato

saldo descrive la situazione corrente dell'oggetto.

Regola

deposita() impedisce che un importo nullo o negativo modifichi il conto.

Composizione prima dell'ereditarietà

La composizione collega oggetti con una relazione «ha un». L'ereditarietà crea una relazione «è un» e va usata soltanto quando il nuovo tipo rispetta davvero il contratto del tipo base.

Composizione

class Ordine: def __init__(self, cliente): self.cliente = cliente self.righe = []

Un ordine ha un cliente e più righe.

Ereditarietà

class Veicolo: def muovi(self): ... class Bicicletta(Veicolo): pass

Una bicicletta è un veicolo.

Dataclass: oggetti che rappresentano dati

Per oggetti semplici, @dataclass genera costruttore, confronto e rappresentazione leggibile.

from dataclasses import dataclass @dataclass class Punto: x: float y: float p = Punto(3, 4) print(p) # Punto(x=3, y=4)

Quando usarla

Record, configurazioni, coordinate e risultati strutturati.

Quando non basta

Se l'oggetto coordina molte operazioni o deve imporre regole complesse sul proprio stato.

Iterable e iteratori

Un iterable può produrre elementi; un iteratore ricorda il punto raggiunto e restituisce il valore successivo.

Iterable

Liste, stringhe, dizionari, file e molti altri oggetti attraversabili.

iter()

Chiede all'oggetto un iteratore.

next()

Ottiene il prossimo elemento; alla fine arriva StopIteration.

In pratica: il ciclo for usa questo protocollo automaticamente.

Consumare un iteratore una volta

Un iteratore avanza: dopo aver restituito un elemento non torna indietro, a meno di crearne uno nuovo.

numeri = iter([10, 20, 30]) print(next(numeri)) # 10 print(next(numeri)) # 20 print(next(numeri)) # 30
⚠️ Attenzione

Liste e tuple si possono attraversare più volte. Un iteratore o un file aperto, invece, può essere già consumato.

Generatori: produrre valori con yield

Una funzione generatrice sospende il lavoro a ogni yield e riprende dalla stessa riga alla richiesta successiva.

def quadrati(limite): for n in range(limite): yield n * n for valore in quadrati(4): print(valore) # 0, 1, 4, 9

Perché serve

Non costruisce subito l'intera collezione: produce un valore alla volta.

Questo riduce la memoria e permette di lavorare con sequenze molto grandi.

Espressioni generatrici

Assomigliano alle list comprehension, ma usano parentesi tonde e calcolano i valori soltanto quando servono.

Lista immediata

quadrati = [n*n for n in range(1_000_000)]

Occupa memoria per tutti i risultati.

Generatore pigro

quadrati = (n*n for n in range(1_000_000))

Conserva soltanto lo stato necessario per continuare.

Pipeline: filtrare senza caricare tutto

Generatori collegati formano una pipeline: ogni fase riceve un elemento, lo trasforma o lo scarta e lo passa avanti.

righe = (riga.strip() for riga in file) non_vuote = (riga for riga in righe if riga) importi = (float(riga) for riga in non_vuote) totale = sum(importi)
Regola: utile per log, grandi CSV e flussi che non devono stare tutti in memoria.

Un ambiente virtuale per ogni progetto

L'ambiente virtuale isola interprete e pacchetti: progetti diversi possono usare versioni diverse senza interferire.

python -m venv .venv # Linux / macOS source .venv/bin/activate # Windows PowerShell .venv\Scripts\Activate.ps1
💡 Controllo

Dopo l'attivazione, python e pip devono puntare dentro la cartella .venv.

Installare pacchetti con pip

pip scarica e installa distribuzioni Python. Va eseguito attraverso l'interprete dell'ambiente attivo.

python -m pip install requests python -m pip show requests python -m pip uninstall requests

Perché python -m pip?

Rende esplicito quale interprete esegue pip e riduce il rischio di installare il pacchetto nell'ambiente sbagliato.

Dichiarare dipendenze riproducibili

Il progetto deve comunicare quali pacchetti richiede. Bloccare ogni versione e dichiarare intervalli compatibili sono decisioni diverse.

requirements.txt

requests==2.32.3 pytest==8.3.5

Elenco semplice, spesso usato per ambienti o applicazioni.

pyproject.toml

dependencies = [ "requests>=2.32,<3" ]

Metadati e dipendenze del progetto.

Lock file

Registra le versioni esatte risolte da uno strumento, per ricreare lo stesso ambiente.

Import stabili, avvio esplicito

Il codice importabile non dovrebbe partire da solo. Un punto di ingresso separato rende test e riuso più semplici.

# negozio/calcoli.py def totale(righe): return sum(r.prezzo for r in righe) # app.py from negozio.calcoli import totale def main(): ... if __name__ == "__main__": main()

Confine utile

I moduli definiscono funzioni e classi.

app.py coordina input, output e avvio.

I test importano i moduli senza eseguire l'applicazione.

Un test rende verificabile una promessa

Un test prepara un caso, esegue il comportamento e confronta il risultato con ciò che dovrebbe accadere.

Arrange

Prepara dati e dipendenze.

Act

Esegue la funzione o il metodo.

Assert

Confronta risultato ottenuto e atteso.

Regola: un test deve fallire per un motivo comprensibile.

Assert: il controllo minimo

L'istruzione assert esprime una condizione che deve essere vera. È utile nei test e per invarianti interne, non per validare input utente.

def media(valori): if not valori: raise ValueError("Lista vuota") return sum(valori) / len(valori) assert media([6, 8, 10]) == 8
⚠️ Distinzione

Gli assert possono essere disattivati dall'interprete. Per errori previsti dell'utente usa eccezioni esplicite.

Test strutturati con unittest

La libreria standard scopre classi e metodi di test, raccoglie risultati e mostra errori riproducibili.

import unittest class TestMedia(unittest.TestCase): def test_valori_normali(self): self.assertEqual(media([6, 8, 10]), 8) def test_lista_vuota(self): with self.assertRaises(ValueError): media([]) if __name__ == "__main__": unittest.main()

Preparare e isolare il contesto

setUp() ricrea le condizioni prima di ogni test. File temporanei e oggetti nuovi impediscono che un test sporchi il successivo.

class TestCarrello(unittest.TestCase): def setUp(self): self.carrello = Carrello() def test_inizialmente_vuoto(self): self.assertEqual( self.carrello.totale(), 0 )

Isolamento

Ogni test parte da uno stato noto.

Determinismo

Stesso input, stesso risultato: rete, orologio e casualità vanno controllati o sostituiti.

Casi normali, limite ed errore

Una funzione non è verificata se il test copre soltanto l'esempio più comodo.

Normale

Valori tipici e risultato atteso.

Limite

Zero, uno, lista vuota, valore massimo o confine tra due rami.

Errore

Tipo sbagliato, dato mancante, file assente o risposta non valida.

Un'API HTTP espone risorse

Il client invia una richiesta a un URL; il server risponde con stato, intestazioni e contenuto.

Metodo

GET legge, POST crea, PUT/PATCH modifica, DELETE rimuove.

URL

https://api.azienda.it/prodotti/42 identifica una risorsa.

Risposta

Codice di stato, header e corpo spesso codificato in JSON.

Fonte: HTTP Semantics — RFC 9110 ↗

Fare una richiesta con requests

Imposta sempre un timeout: senza limite, il programma può restare in attesa indefinitamente.

import requests risposta = requests.get( "https://api.azienda.it/prodotti", params={"categoria": "ufficio"}, timeout=10, ) risposta.raise_for_status() prodotti = risposta.json()

Stato HTTP ed errori di rete

Una risposta ricevuta può comunque indicare un errore. Inoltre DNS, connessione, TLS o timeout possono fallire prima della risposta.

Codici frequenti

200 riuscita · 201 creata · 400 richiesta errata · 401/403 accesso negato · 404 assente · 500 errore server.

try: risposta = requests.get(url, timeout=10) risposta.raise_for_status() except requests.Timeout: print("Servizio troppo lento") except requests.RequestException as errore: print("Richiesta fallita", errore)
Fonte: Domain Name System — ICANN ↗

Autenticazione, pagine e limiti

Le API reali raramente restituiscono tutto senza regole: richiedono credenziali, dividono i risultati e limitano la frequenza.

Token

Si invia nell'header previsto. Non va scritto nel codice o pubblicato nel repository.

Paginazione

La risposta indica pagina successiva, cursore o numero totale di risultati.

Rate limit

Se arriva 429, attendi secondo le indicazioni del server invece di riprovare senza pausa.

SQLite: un database dentro un file

SQLite conserva tabelle, relazioni e indici in un singolo file, senza richiedere un server separato.

Tabella

Righe con la stessa struttura di colonne.

Chiave primaria

Identifica ogni record senza ambiguità.

Query SQL

Inserisce, cerca, aggiorna e cancella dati.

Quando usarlo: dati strutturati, ricerche e aggiornamenti più sicuri di un CSV.
Fonte: Modulo sqlite3 — documentazione Python ↗

Creare tabella e connessione

Il blocco with db conferma o annulla la transazione; finally chiude la connessione anche in caso di errore.

import sqlite3 db = sqlite3.connect("negozio.db") try: with db: db.execute(""" CREATE TABLE IF NOT EXISTS prodotti ( id INTEGER PRIMARY KEY, nome TEXT NOT NULL, prezzo REAL NOT NULL CHECK (prezzo >= 0) ) """) finally: db.close()

Parametri SQL, mai concatenazione

I segnaposto separano istruzione e dati, gestiscono correttamente i tipi e prevengono SQL injection.

Da evitare

sql = "SELECT * FROM prodotti WHERE nome = '" + nome + "'"

Il dato può cambiare il significato della query.

Corretto

righe = db.execute( "SELECT * FROM prodotti WHERE nome = ?", (nome,), ).fetchall()

La query resta separata dal valore.

Dal CRUD a una funzione verificabile

Raggruppa ogni operazione del database in una funzione con input, risultato e responsabilità chiari. Passare la connessione facilita i test con un database temporaneo.

def aggiungi_prodotto(db, nome, prezzo): cursore = db.execute( "INSERT INTO prodotti(nome, prezzo) VALUES (?, ?)", (nome, prezzo), ) return cursore.lastrowid

Create

INSERT aggiunge un record.

Read

SELECT restituisce righe.

Update / Delete

Modificano o rimuovono record selezionati.
